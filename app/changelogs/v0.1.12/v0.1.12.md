# SourceFlow v0.1.12

## Highlights

- Cloud sync (S3) gains provider presets: one-click endpoint/region/addressing fill for Cloudflare R2, Aliyun OSS, and Tencent COS with least-privilege and security guidance, plus a Test Connection button that verifies credentials and read/write permissions before saving.
- Workbench rule engine completed across three phases: rule editor, run dialog, event triggers, scheduled triggers, skill actions, and rule import/export.
- AI assistant adds asset vision attachments with an OCR transcript cache, asset mentions in context search and sources, and a related-notes dock panel powered by semantic search.
- Document tree supports drag-to-sort in custom sort mode (Alt-drag moves across levels).
- New Arch Linux packaging (PKGBUILD): local pacman install and AUR (sourceflow-bin) publishing.

## Cloud Sync

- The backup settings page now exposes a prominent Synology quick-connect entry. One click selects WebDAV and applies Synology HTTPS/port defaults, while the same panel continues to support generic WebDAV devices.
- The S3 panel adds a provider preset dropdown: choosing Cloudflare R2 / Aliyun OSS / Tencent COS auto-fills endpoint templates, region, path-style/virtual-hosted addressing, and placeholders; the current preset is auto-detected from the saved endpoint.
- Each preset ships setup guidance and least-privilege recommendations. Provider secrets are excluded from workspace configuration and recovery profiles, and desktop builds use the operating-system credential vault when available.
- Backup encryption now uses a user-facing master password to wrap the random repository key. Recovery profiles contain only the encrypted key envelope, so another device can recover with the same password without copying a raw repo key.
- New POST /api/sync/testSyncProviderS3: verifies endpoint, credentials, and read/write permissions via a temporary object round-trip (upload/download/compare/remove) without changing the saved config; also usable while the boot read-only guard is active.
- New SYNC_S3_PROVIDERS.md provider guide with least-privilege policy examples and an error troubleshooting table.
- Fixes: unified Forgejo TLS strategy across API/git/curl channels; two-stage push (LFS objects first, then refs with --no-verify) so slow links no longer abort batch uploads.

## Workbench Rules (R8)

- Rule editor and run dialog: visual editing of triggers and actions with honest run-time semantics.
- Event and scheduled triggers drive rules; skill actions callable from rules; rule import/export.

## AI Assistant

- Asset vision attachments and OCR: image assets usable as vision input with an OCR transcript cache and usage accounting, toggleable.
- Asset mentions enter context search and sources.
- Related-notes dock panel based on semantic search.
- Unified context budget: system prompt plus history measured against the model window; user context-window override; context switch notice and token usage meter.
- Patch review moved to a non-modal side panel; inline instruction input in the selection bar; move-note-to-path tool gated by capabilities.
- Fixes: reserve budget for the current message, input stability guardrails, dock input focus retention.

## Editor

- Mermaid: theme-aware re-render, retry on failure, double-click zoom lightbox.
- Code block run falls back to python3 on systems without python.
- Cross-block paste refinements for list selections (phase 2).

## Documents & UI

- Homepage becomes a note shortcut with hardened opening and improved shortcut entries.
- Template library import/export with duplicate guard.
- Document tree: notebook context kept in batch delete; explicit errors on delete failures.
- Embedding/security dirty guards and provider catalog.

## Platform & Packaging

- Windows no longer asks users to add SourceFlow or the workspace to Microsoft Defender exclusions. The custom elevation helper, exclusion command, startup prompt, and persisted exclusion flag have been removed; antivirus scanning remains enabled for notes and attachments.
- New packaging/arch: sourceflow-bin PKGBUILD (/opt install, desktop entry, setuid sandbox, deps derived from readelf direct linkage) with AUR publishing instructions.
- The Linux x64 build now automatically emits AppImage, deb, tar.gz, portable tar.gz, and a locally validated `.pkg.tar.zst` when `makepkg` is available; the Arch package can also be rebuilt independently from the Linux tarball.
- The build entrypoint now selects artifacts from the host automatically: Windows builds the exe installer, macOS builds its native installer, and Linux builds all native Linux packages plus a structurally validated Windows x64 installer through MinGW and Wine.
- Upgrade the project package manager to pnpm 12.10.1 and explicitly allow only the dependency build scripts required by Electron packaging.
- Release tooling: --preserve-remote-assets for completing multi-platform releases from another machine; proxy auto-detection for streaming uploads; --skip-push allowed when completing an existing release.
- Builds: tolerate broken ambient GOROOT and .DS_Store races; clean broken pnpm links before installer builds; kernel tolerates transient filesystem errors instead of exiting fatally.
