# SourceFlow v0.1.12

## 亮点

- 云端同步（S3）新增云服务商预设：Cloudflare R2 / 阿里云 OSS / 腾讯云 COS 一键填充 Endpoint、Region 与寻址方式，并附最小权限与安全配置指引；新增"测试连接"按钮，保存前即可验证凭证与读写权限。
- 工作台规则引擎完成三阶段：规则编辑器、运行对话框、事件触发、定时触发、技能动作，以及规则导入/导出。
- AI 助手支持资产视觉附件与 OCR 转录缓存、资产引用进入上下文搜索与来源、"相关笔记"语义检索停靠面板。
- 文档树自定义排序模式支持拖拽排序（Alt 拖动可跨层级移动）。
- 新增 Arch Linux 打包（PKGBUILD）：支持 pacman 本地安装与 AUR（sourceflow-bin）发布。

## 云端同步

- S3 配置面板新增"云服务商预设"下拉：选择 Cloudflare R2 / 阿里云 OSS / 腾讯云 COS 后自动填充 Endpoint 模板、Region、Path-style/Virtual-hosted 寻址与占位提示，并按已保存 Endpoint 自动识别当前预设。
- 每个预设附配置指引：R2 API 令牌权限、OSS RAM 最小权限策略动作清单、COS Bucket 命名（名称-APPID）等；面板同时提示快照端到端加密与 AK/SK 明文存储的安全注意事项。
- 新增 POST /api/sync/testSyncProviderS3：通过临时对象"上传→下载→比对→删除"完整验证端点、凭证与读写权限，不改动已保存配置；启动只读保护期间亦可使用。
- 新增 SYNC_S3_PROVIDERS.md 配置指南（含各家最小权限策略示例与常见错误对照表）。
- 修复：内网 Forgejo 同步的 TLS 策略在 API/git/curl 三通道统一；推送改为"LFS 先行、refs 随后"两阶段，慢链路不再整批中断。

## 工作台规则（R8）

- 规则编辑器与运行对话框：可视化编辑触发条件与动作，手动运行可见真实执行语义。
- 事件触发与定时触发：文档事件、时间计划均可驱动规则；运行时间语义如实呈现。
- 技能动作：规则可调用技能；支持规则导入/导出。

## AI 助手

- 资产视觉附件与 OCR：图片资产可作为视觉输入，OCR 转录缓存并计入用量统计，可开关。
- 资产引用：@ 提及的资产进入上下文搜索与来源列表。
- 相关笔记停靠面板：基于语义搜索推荐相关笔记。
- 统一上下文预算：系统提示词与历史共同计入模型窗口；支持用户自定义上下文窗口覆盖；上下文切换提示与 token 用量表。
- 补丁审查改为非模态侧栏面板；选择工具栏支持行内指令输入；移动笔记到指定路径工具（受能力开关约束）。
- 修复：为当前消息预留上下文预算、输入稳定性护栏、停靠输入焦点保持等。

## 编辑器

- Mermaid：跟随明暗主题重渲染、渲染失败可重试、双击缩放查看。
- 代码块运行：无 python 命令的系统自动使用 python3。
- 列表选区的跨块粘贴行为优化（第二阶段）。

## 文档与界面

- 主页改为笔记快捷入口，打开路径加固，快捷键入口优化。
- 模板库支持导入/导出与重名保护。
- 文档树：批量删除保留笔记本上下文；删除失败显示明确错误。
- 嵌入/安全设置脏状态守卫与供应商目录。

## 平台与打包

- 新增 packaging/arch：sourceflow-bin PKGBUILD（/opt 安装、桌面入口、setuid 沙箱、依赖由 readelf 直接链接库推导），附 AUR 发布说明。
- 发布工具：新增 --preserve-remote-assets 便于跨机器补齐多平台资产；流式上传自动探测代理；--skip-push 允许补齐既有 Release。
- 构建：容忍异常 GOROOT 与 .DS_Store 竞态；安装器构建前清理损坏的 pnpm 链接；内核容忍瞬时文件系统错误而非致命退出。
