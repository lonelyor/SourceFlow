# SourceFlow v0.1.3

## Highlights

- The AI assistant sidebar is split into clearer runtime, state, message, event, and rendering modules, reducing future maintenance and regression risk.
- The assistant improves iterative chat workflows with pinned target notes, edit-and-regenerate for sent prompts, collapsed long prompts, copied messages with image summaries, and direct insertion of the latest reply into the current note.
- Tool use now has clearer policy controls. Tools can be enabled per profile with read-only, confirm-write, or recommended policies, and recent tool calls stay visible in the audit panel.
- Fixed mojibake in AI quick-action menu text, restoring readable labels for copy result, replace selection, insert into note, save to results, and continue in chat.
- China AI model presets were refreshed, Alibaba Bailian / Qwen was added as a provider, and streaming plus tool-call support continues to improve for OpenAI Compatible, Anthropic, and Gemini providers.

## AI Assistant

- Session selection, profile switching, target-note selection, tool configuration, and audit panels now live in smaller dedicated modules.
- Image input still enforces count and size limits, with clearer errors for oversized images and non-image files.
- Long user prompts collapse by default so large context blocks do not dominate the chat area.
- Editing a previous user prompt preserves the current draft and images, and canceling the edit restores the previous composer state.
- Tool policies are saved on the active AI profile, so they do not need to be reconfigured every time the assistant opens.

## Build And Quality

- Added `test:ai-dock-runtime` for the assistant Dock runtime behavior, including tool toggles, profile switching, and the settings entry.
- The stability gate documentation now calls out AI assistant isolation: AI or tool-call failures must not break note editing, search, or sync.
- Release notes, product-quality docs, and rollback guidance were updated for the current stable stage.

## Upgrade Notes

- Upgrade if you regularly use the AI assistant, image prompts, selected-text AI actions, or AI tool calls.
- Release assets include `SHA256SUMS.txt` for download verification.
