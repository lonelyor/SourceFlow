# SourceFlow v0.1.6

## 重点

- 修复多处可能影响笔记安全的底层问题，优先保护 `.sf` 笔记文件不被异常写入、读取或修复流程破坏。
- 修复 Protyle Block DOM 保真问题，避免前端过滤后笔记被压平成一行或丢失格式。
- 加强事务失败处理，批量插入/删除失败时会回滚并返回错误，避免部分写入造成笔记状态不一致。
- 收紧文件树、搜索、导入和上传边界，降低路径越界、SQL 注入、zip 炸弹和超大上传风险。
- 修复 Linux/WSL 编译中的大小写导入问题，确保发布构建可以稳定通过。
- 文档树最近编辑和常用文档默认折叠，新增文档树字号自定义设置，留空保持当前默认显示。

## 稳定性与安全

- `.sf` 写入统一走安全写入路径，避免先截断原文件再写入导致失败时清空笔记。
- Protyle 正文加载和 SourceFlow 内部粘贴保留原始笔记 Block DOM，不再解析或清洗整篇笔记正文。
- 读取、索引和文档列表路径不再因为 IAL 缺失或异常文件名自动移动/删除笔记文件。
- 文档列表遇到非法 IAL `id` 时回退文件名 ID，避免异常元数据触发崩溃。
- 文档树缓存不再复用可变 AST 实例，避免重建索引或渲染流程污染真实笔记树。
- 已有非空笔记不允许被空 AST 覆盖，防止异常状态被持久化为空白笔记。
- 事务队列、单事务等待和 SQL 写队列增加超时与诊断日志，避免无界等待。

## 安全边界

- `/api/filetree/listDocTree` 入口路径约束在笔记本目录内，拒绝越界路径。
- 文档搜索改为参数化 SQL，搜索词和排除 ID 不再拼接进 SQL 字符串。
- 导入 `.sf.zip` / `.zip` / 本地 Markdown 前校验笔记本 ID。
- zip 解压限制文件数量、单文件大小、总解压大小、压缩比和路径穿越。
- 普通资源上传限制单次文件数量、单文件大小和总大小。
- AI patch 写入禁止删除或整体替换当前笔记根文档，外部 Markdown 写入会重新生成块 ID。

## 文档树

- 最近编辑与常用文档首次展示默认折叠，已有本地折叠状态会继续按用户选择恢复。
- “设置 > 外观 > 文档树”新增文档树字号设置，支持 10-20 px，留空使用主题默认字号。
