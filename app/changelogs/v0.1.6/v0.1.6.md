# SourceFlow v0.1.6

## Highlights

- Block numbers now display in the left margin (VSCode-style) instead of inline badges, keeping content clean and readable.
- New "Always show block type icon" setting lets you keep the gutter icon visible after hovering instead of it disappearing on scroll.
- Kernel block query, tree cache, and database optimizations for improved performance.
- Frontend improvements across template picker, file tree dock, navigation menu, AV table runtime, and render scheduler.

## Editor

- **Block numbers in left margin** — block numbers are positioned in the editor's left padding area, right-aligned with subtle color, no longer mixed into content as inline badges.
- **Always show block type icon** — new toggle in **Settings → Editor**. When enabled, the block type gutter icon persists in the left margin after hovering instead of disappearing on scroll or mouse leave.

## Platform

- Kernel: block query optimization, tree cache enhancement, transaction extension, database schema updates
- AV table runtime and highlight render improvements
- Template picker, navigation menu, EventBus refactor
- File tree dock and protyle menu enhancements
- Render scheduler and paste utility updates

## Test & Quality

- Added `testEditorStructureGuide` with 15 automated checks covering config, types, UI, i18n, SCSS, hideElements logic, and global events.
