## Highlights

- Backup settings now expose Synology quick connect directly: one click selects WebDAV and Synology HTTPS/5006 defaults, while remaining compatible with every standards-compliant WebDAV device.
- WebDAV and S3 provide encrypted snapshot synchronization across devices. Credentials stay in the operating-system vault and recovery profiles contain no plaintext passwords.
- A backup master password wraps the repository key so a new device can recover with the same password; local notes and attachments remain unencrypted on disk.
- Microsoft Defender exclusion prompts and the custom elevation helper have been removed completely; notes and attachments remain covered by antivirus scanning.
- The core note workflow remains local-first, with continued focus on editing, assets, sync, and cross-device stability.
- The release flow uses artifacts produced by `编译.py` and writes this body plus checksums into the GitHub Release.
- Plugins and Bazaar stay optional: plugins are disabled after install until the user reviews source, permissions, and SHA-256.
- The release target is selected by `发布.py --platform/--arch`; the GitHub Release asset list is the source of truth.
