# SourceFlow v0.1.4

## Highlights

- File tree overhaul: more reliable drag-and-drop moves with drop targets inside expanded folders and at list ends; new appearance controls for guide lines, doc counts, drop hints, and expandable-wait feedback; quick filter, current path bar, recent docs, and favorites navigation.
- Editor reading experience: persistent H1-H6 heading-level badges and optional top-level block numbers; sticky current-heading bar synced on scroll with bidirectional outline highlighting; improved collapsed-heading visuals; empty-doc and duplicate-name cleanup hints; copy menu now offers block-location links with readable path context.
- Large-document performance: a new render scheduler prioritizes visible-area content on first paint; off-screen code blocks, charts, math, and embeds are deferred via IntersectionObserver; scroll and resize handlers debounce sticky-row calculations to visible area only.
- AI assistant improvements: a reject button for pending tool calls; agentic loop for multi-round tool invocation; native function calling for both Anthropic and Gemini providers (streaming + non-streaming).
- Test coverage expanded with 20+ new runtime behavior tests covering tool confirm/reject, Enter send, Escape cancel, edit-resend, image attachment paste/pick/remove, and message actions.

## File Tree

- Drag-move targets expanded: drop on target doc, notebook root, expanded folder whitespace, and list end. Works in any sort mode.
- Move vs. sort split: plain drag always moves; custom sort uses dedicated "Move Up / Move Down" context-menu items.
- Appearance controls: guide lines (off by default), drop hints, current-path/selected/drag-target distinction, expandable-wait feedback, density (compact/default/loose).
- Counts: child-doc count toggle (off by default) and total-doc count toggle (on by default).
- Navigation: quick filter, current path bar, recent-docs entry, and lightweight favorites entry.

## Editor

- Structure guides: persistent H1-H6 badges (on by default) and optional top-level block numbers (off by default). Neither is saved into document content.
- Heading context sync: sticky current-heading bar on scroll, bidirectional outline highlighting, enhanced collapsed-heading visuals.
- Cleanup hints: empty-content and same-notebook-duplicate-name notices shown in the current editor.
- Block-location links: "Copy Block Location Link" in the copy menu outputs a Markdown sf://blocks/ link with readable path and block text.
- Performance: render scheduler splits work into 12 ms frames; IntersectionObserver defers off-screen rendering; scroll and resize handlers are debounced.

## AI Assistant

- Tool reject: pending tool calls can now be explicitly rejected; backend records a rejected status and audit trail.
- Agentic loop: multi-round tool invocation with auto-execution for auto-mode tools and pause for confirm-mode tools.
- Anthropic native tool_use: both streaming and non-streaming modes support native function calling.
- Gemini native function calling: both streaming and non-streaming modes support functionDeclarations.

## Upgrade Notes

- Upgrade if you manage many docs in the file tree, read or navigate long documents, or need more reliable multi-model AI tool calls.
- Release assets include `SHA256SUMS.txt` for download verification.
