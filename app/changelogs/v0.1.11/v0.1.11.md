# SourceFlow v0.1.11

## Highlights

- Fixes the Windows installer "Add Microsoft Defender exclusion" feature: the `microsoftDefenderExcluded` field was missing from the config struct, so a successful exclusion could not be recorded and the elevation prompt reappeared on every launch. The field is restored and the exclusion state now persists.
- Fixes a cross-platform defect in sensitive path detection: on Windows, `filepath.Clean` rewrites UNIX-style paths (such as `/etc/passwd`) with backslashes, so system-critical directory prefixes never matched. Comparisons are now normalized to forward slashes for both Windows and UNIX-style paths, with Start Menu and home-directory prefixes aligned to the same convention.
- Cross-platform build verification is now part of the release flow: the full Windows build (installer + portable) and macOS cross-compile checks (arm64/amd64) all pass, keeping the source buildable on both Windows and macOS.

## Verification

- Go kernel target tests (util/conf), frontend TypeScript checks, full Windows build (installer + portable artifacts validated), and macOS cross-compile checks all pass.
