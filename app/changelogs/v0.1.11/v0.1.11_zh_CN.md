# SourceFlow v0.1.11

## 重点

- 修复 Windows 安装版「加入 Microsoft Defender 排除项」功能失效的问题：配置结构缺失 `microsoftDefenderExcluded` 字段，成功加入排除项后状态无法持久化，每次启动都会重复弹出提权确认窗口；现恢复字段定义，排除状态正确记录，只提示一次。
- 修复敏感路径检测在 Windows 上的跨平台缺陷：`filepath.Clean` 在 Windows 会把 UNIX 风格路径（如 `/etc/passwd`）改写为反斜杠形式，导致系统核心目录前缀全部匹配失败；现统一转换为正斜杠比较，Windows 与 UNIX 风格路径均可正确判定，开始菜单、家目录等前缀同步采用同一口径。
- 双平台编译验证纳入发布流程：Windows 完整编译（installer + portable）与 macOS 双架构（arm64/amd64）交叉编译检查全部通过，保证源码在 Windows 与 macOS 上均可构建。

## 验证

- 通过 Go 内核目标测试（util/conf）、前端 TypeScript 检查、Windows 完整编译（installer + portable 产物验证）与 macOS 交叉编译检查。
