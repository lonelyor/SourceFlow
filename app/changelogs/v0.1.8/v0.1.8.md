# SourceFlow v0.1.8

## Highlights

- Introduces reversible AI write history: Dock write actions now produce traceable records, suspicious writes require confirmation, the inbox is saved atomically, and writes can be reviewed and rolled back.
- Homepage is reworked into a note shortcut: any note can be set as the homepage, and opening the homepage jumps straight into it with a more robust loading path.
- AI Dock gains Kilo-style modes, and assistant tasks and session state are persisted so they survive restarts.
- Tightens the AI write safety boundary: explicit save auditing, source and context scope checks, and removal of the global total deadline on streaming responses so long generations are no longer cut off.
- Editor selection and paste safety: copy, cut, and paste now operate on a unified selection scope, preventing misplaced-selection writes.
- Unifies the app icon set to a black-background variant and fixes icons that were accidentally corrupted in the previous version (Windows icon regressed to a single 16×16, tray and About-page icons were wrong).

## AI Assistant & Write Safety

- Adds reversible AI write history: Dock write actions enter a rollback-capable history that works alongside patch review, so content can be validated before writing and traced afterward.
- Suspicious writes (large divergence, out-of-scope, etc.) now require explicit user confirmation instead of being silently persisted.
- AI inbox saving is now atomic; a mid-write failure no longer leaves partial data behind.
- Explicit save commands are audited, with clear keep / replace / clear semantics.
- Source context and save flows are further hardened: stricter boundary checks on `@` references, source search, and context budget.
- Streaming AI responses no longer carry a global total deadline; per-step timeouts replace it, so long document generation is no longer interrupted wholesale.
- Removes legacy local-history fallback and old AI config read paths so writes and configuration converge on a single entry point.

## AI Dock

- Dock adds Kilo-style multi-mode workflows suited to different writing scenarios.
- Assistant tasks and session state are persisted; in-progress tasks resume after a restart, and pinned sessions stay idempotent.
- Fixes the Dock input box losing focus during streaming render, making input interaction more stable.
- Adds input stability guardrails so render jitter no longer affects content being typed.

## Homepage & Navigation

- The homepage can be set as a shortcut to a specific note; opening the homepage enters that note directly.
- Homepage shortcut entry is improved; when no note is set or the target is unavailable, it shows an actionable prompt instead of failing silently.
- Hardens the homepage note-opening path against missing targets and concurrent opens.

## Editor

- Paste selection safety is hardened: the selection range is validated before paste, preventing misplaced-selection overwrites.
- Copy and cut compute over a unified selection scope, giving more accurate content extraction across blocks.
- Closes auditing gaps on the paste and history paths so write actions are traceable.

## Refactoring & Engineering

- The attribute view modules are split by responsibility to reduce coupling and ease future maintenance.
- Legacy AI config paths and local-history fallback are removed, converging on the current safety entry point.
- Adds product readiness and resilience gates covering main-flow E2E, kernel boot regression, and abnormal-exit scenarios.
- Fixes pre-build pnpm link cleanup for installers to avoid intermittent packaging failures.

## Icons & UI

- Unifies the app icon set to a black-background variant across macOS (full-size icns), Windows (multi-size ico), and in-app surfaces (splash, tray, About page).
- Fixes icons accidentally corrupted in the previous version: the Windows icon had regressed to a single 16×16, and tray/window icons displayed incorrectly.

## AI Usability & Dynamic Context Budget

- Note context is now sized to each model's real context window (resolved from Gemini / OpenRouter / Ollama / Anthropic APIs) instead of a fixed cap, and the backend budget measures system prompt and history together so large-window models are no longer truncated needlessly.
- In-note AI gains zero-config first-run guidance, a one-click model quick-switcher, stop-generation with classified (auth vs network) errors in the skill dialog, a grouped and searchable skill menu, unified selection-bar vocabulary, default AI shortcuts, and a non-modal side panel for patch review.
- AI settings are compacted: advanced sections and tool permissions collapse by default, test and save share one footer row, and switching profiles warns on unsaved changes.
- The dormant legacy OpenAI config (conf.AI / IOpenAI) is removed; configuration converges on the assistant AI profile system.

## Validation

- Regenerated installer and portable packages matching `0.1.8` before release; no older version artifacts are reused.
- Passed Go kernel target tests, frontend TypeScript checks, product readiness / resilience gates, and AI write history and Dock stability regression.
