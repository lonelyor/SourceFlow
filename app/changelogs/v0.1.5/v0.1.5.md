# SourceFlow v0.1.5

## Highlights

- The AI assistant is now a more complete AI-native note agent layer, with scoped context, reviewable patch/diff writes, ghost drafts, inline command iteration, batch Agent execution, and local audit history.
- Semantic search infrastructure is now available: configure an Embedding service, index the current note or all notes, and switch the search panel into semantic mode.
- Added a local acceptance `fake` Provider with no API key requirement, deterministic replies, mock streaming, static model listing, connectivity checks, and tool dry-run patch previews.
- Usability refinements continue: the blank area in the file tree can open the global more menu and create notes; first-launch security notice and repo key copy support were added.
- Stability fixes cover Go vet blockers, test fixture path compatibility, and the mobile Z-mode exit-button build guard.

## AI Assistant

- Write-capable skills now default to reviewable patches instead of direct tool execution.
- Patch apply supports `create-note`, `create-child-note`, `delete-block`, `rename-note`, and `set-attrs`.
- Selection replacement stops and warns when the original text is missing or ambiguous.
- Ghost drafts stay visible while the patch review dialog is open and are cleaned up when the review is accepted, rejected, closed, or adjusted.
- Inline commands support `Ctrl+I`, `Ctrl+J`, recent prompts, and up to three rounds of adjustment on the same selection.
- The Agent panel can create batch tasks from the current input, execute items one by one, pause, cancel, resume, retry failed items, and review each item patch.
- AI operation history now records source, risk, session, profile, target, error, and results, with low-risk rollback for AI-created notes and child notes.

## Search And Organization

- Added Embedding settings for Ollama / OpenAI-compatible Embedding APIs.
- Vector storage uses a local JSON-backed store with cosine similarity search.
- The search panel now has a semantic search mode.
- Settings can trigger indexing for the current note or all notes.

## Release And Validation

- Version anchors are aligned across `app/package.json`, `kernel/util/working.go`, and Windows Appx manifests.
- Windows x64 installer and portable builds continue to be built and validated by `编译.py`.
- Release assets include the installer, portable package, browser capture extension, and `SHA256SUMS.txt`.
