# SourceFlow v0.1.5

## 本次更新重点

- AI 助手升级为更完整的 AI 原生笔记代理层：补齐上下文裁剪、写入型 patch/diff 审阅、ghost draft 临时预览、内联指令连续编辑、Agent 批量任务执行和本地审计历史。
- 语义搜索基础设施上线：支持配置 Embedding 服务、索引当前或全部笔记，并在搜索面板中切换语义搜索模式。
- 新增本地验收用 `fake` Provider：无需 API Key，支持配置连通测试、模型列表、确定性回复、mock stream 和工具 dry-run patch 预览。
- 易用性继续补齐：文档树空白区域右键可打开全局更多菜单并新建笔记；新增首启安全提示和仓库密钥复制能力。
- 稳定性修复：修复 Go vet 阻断项、测试路径兼容问题，以及移动端 Z 模式退出按钮构建守卫。

## AI 助手

- 写入型能力默认进入可审阅 patch，不再把真实写入作为工具确认的默认路径。
- Patch apply 支持 `create-note`、`create-child-note`、`delete-block`、`rename-note`、`set-attrs` 等操作。
- 选区替换遇到重复原文或原文缺失时会停止自动替换并提示，避免误改。
- Ghost draft 在 patch 审阅窗口生命周期内保持可见，接受、拒绝、关闭或继续调整后再清理。
- 内联指令支持 `Ctrl+I` 打开、`Ctrl+J` 续写、最近指令和最多 3 轮连续调整。
- Agent 面板支持从当前输入创建批量任务，逐项执行、暂停、取消、恢复、失败重试，并对每个任务项进行 patch 接受或拒绝。
- AI 操作历史记录补齐 source、risk、session、profile、target、error、results，并支持低风险回滚 AI 创建的新笔记和子文档。

## 搜索与知识整理

- 新增 Embedding 配置入口，支持 Ollama / OpenAI 兼容 Embedding API。
- 向量存储使用本地 JSON 持久化，并支持余弦相似度搜索。
- 搜索面板新增“语义搜索”模式切换。
- 可从设置中触发当前笔记或全部笔记索引。

## 发布与验证

- 版本号已统一到 `app/package.json`、`kernel/util/working.go` 和 Windows Appx manifest。
- Windows x64 安装包和便携包继续由 `编译.py` 统一构建与校验。
- 发布资产包含安装包、便携包、浏览器采集扩展和 `SHA256SUMS.txt`。
