## Overview

SourceFlow v0.1.0 release notes. This file was generated by `发布.py`; review and edit it before publishing.

## Highlights

- The core note workflow remains local-first, with continued focus on editing, assets, sync, and cross-device stability.
- `编译.py` is now the self-contained build entrypoint for Windows, Linux, macOS, and same-OS x64/arm64 targets; Apple Silicon Macs resolve to macOS arm64.
- `发布.py` is now the self-contained release entrypoint. It stages installers, portable packages, the browser extension zip, release notes, and `SHA256SUMS.txt`.
- Release notes can be generated and reviewed before publishing with `python 发布.py --release-notes-only --version-bump none`.
- `插件商城.py` adds a one-command `plugins/` to GitHub Pages Bazaar workflow for `lonelyor/SourceFlow-plugins`: validation, smoke test, packaging, hashing, index generation, and push.
- `Paper Polish` adds a focused reading polish plugin with calmer typography, compact density, soft contrast, and a top-bar toggle.
- Plugins and Bazaar stay optional: plugins are disabled after install until the user reviews source, permissions, and SHA-256.

## New and Improved

- Cross-platform builds: environment checks, tool installation, Node/pnpm/Go checks, macOS CLT/Homebrew checks, and target build orchestration are centralized in `编译.py`.
- Release automation: `发布.py` no longer depends on external validation scripts for its core release flow and can validate portable packages, Docker releases, and staged assets directly.
- Release notes: when a version has no changelog yet, the release script generates Chinese and English notes and uses the Chinese file as the GitHub Release body.
- Plugin Bazaar: `插件商城.py` generates `submissions/plugins/*.json`, plugin ZIPs, static Bazaar `dist/`, and can push the standalone `lonelyor/SourceFlow-plugins` repository to GitHub.
- Plugin safety review: Bazaar entries keep permissions, supported platforms, source URL, and package SHA-256 for install-time review.
- Secret safety: the plugin publish flow now scans plugin source and exported repositories for high-risk secrets, and GitHub tokens are only used through transient auth context.
- Quality gate: the release flow can run kernel Go tests, plugin-system smoke tests, and frontend typecheck; `--skip-quality-gate` is available for explicit bypasses.
