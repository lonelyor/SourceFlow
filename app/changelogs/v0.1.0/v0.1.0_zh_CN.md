## 本次发布重点

- 笔记主流程保持本地优先，围绕创建、编辑、资源附件、同步和跨设备使用继续收敛稳定性。
- `编译.py` 已改为自洽编译入口，支持 Windows、Linux、macOS，以及 x64/arm64 同系统目标；在 M 系列 Mac 上会解析为 macOS arm64。
- `发布.py` 已改为自洽发布入口，优先使用 `编译.py` 产物，并在 GitHub Release 中写入本说明、安装包、便携包、浏览器扩展包和 `SHA256SUMS.txt`。
- Release 说明支持自动生成和人工审核：运行 `python 发布.py --release-notes-only --version-bump none` 可先生成说明，再编辑删减。
- 新增插件商城维护脚本 `插件商城.py`，本地插件统一放在 `plugins/` 下，可完成校验、烟测、打包、哈希、集市索引生成，并一键推送到 `lonelyor/SourceFlow-plugins`。
- 新增 `Paper Polish / 纸面美化` 插件，提供专注阅读排版、紧凑密度、柔和对比和顶部栏快速切换。
- 插件与集市能力保持可选：插件安装后默认不运行，启用前展示来源、权限和 SHA-256 摘要。

## 新增和改进

- 跨平台编译：环境检测、工具安装、Node/pnpm/Go 检查、macOS 命令行工具/Homebrew 检查和对应平台构建流程集中到 `编译.py`。
- 发布自动化：发布脚本不再依赖外部校验脚本完成核心流程，能自行校验便携包、Docker 发布包和 staged assets。
- 发布说明：若当前版本没有 changelog，发布脚本会生成中英文说明文件，并把中文版作为 GitHub Release 正文。
- 插件商城：`插件商城.py` 支持从 `plugins/<plugin-name>/` 生成 `submissions/plugins/*.json`、插件 ZIP、静态 Bazaar `dist/`，并可推送独立 GitHub 集市仓库 `lonelyor/SourceFlow-plugins`。
- 插件安全提示：集市条目保留权限、适用平台、来源 URL、安装包 SHA-256，便于安装前审核。
- 密钥安全：插件发布链路增加源码和导出仓库 secret scan，GitHub token 只通过临时认证上下文使用，不写入导出仓库。
- 质量门禁：发布流程增加最小质量门禁，可执行内核 Go 测试、插件系统烟测和前端 typecheck；必要时可用 `--skip-quality-gate` 显式跳过。
