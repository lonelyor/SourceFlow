# SourceFlow v0.1.9

## 重点

- Mermaid 图表跟随应用主题：浅色/深色切换时已渲染的图表会重新渲染（含后台标签页），使用应用字体栈，浅色模式下带卡片背景。
- Mermaid 块更健壮：渲染失败可通过刷新图标重试、错误以多行文本展示、双击图表打开缩放/旋转/翻转灯箱预览。
- 修复中文笔记的动态上下文预算：前端改为与后端一致的 CJK 感知估算（1 个中文字符 ≈ 1 token），中文笔记不再占用 4 倍真实预算、挤爆小窗口模型。
- Ollama 模型改为从 API 解析真实上下文窗口，不再回退默认值。
- 修复源码构建启动即崩溃（"Cannot access 'X' before initialization"）的问题，根因是基础插件 API 的循环引用。

## 编辑器

- 浅色/深色主题切换时 Mermaid 块重新渲染，后台标签页中的图表通过 IntersectionObserver 兜底处理。
- Mermaid 按主题初始化一次而非每次渲染都初始化，并跟随应用字体栈（`--b3-font-family`）而不是写死的 sans-serif。
- 浅色模式下 Mermaid 使用卡片背景与圆角；深色模式保持透明（mermaid 在深色下绘制浅色文字，不适合白色背景）。
- 渲染失败可恢复：重试状态保持干净、对 mermaid 错误元素做空值检查、错误以多行文本展示。
- Mermaid 块增加刷新图标（与 echarts 一致）。
- 双击 Mermaid 图表打开 viewerjs 灯箱，支持缩放/旋转/翻转，与现有图片预览体验一致。

## AI 助手

- 前端笔记上下文额度改为 CJK 感知（1 个中文字符 ≈ 1 token），与后端估算器同一口径。此前按固定 x4 的 token-字符换算使中文笔记拿到 4 倍真实预算，溢出小上下文窗口并把历史预算压到 0。
- Ollama 模型从提供方 API 解析真实上下文窗口，不再使用回退默认值。

## 插件系统与稳定性

- 基础插件 API 改为在插件加载时惰性构建，而非模块初始化时立即读取导入绑定，修复了 tabUtil → layout/util → plugin/loader → plugin/API 循环引用导致的 TDZ 崩溃（源码构建启动必崩）。

## 验证

- 发布前重新生成与 `0.1.9` 版本号一致的安装包与便携包，不复用旧版本产物。
- 通过 Go 内核目标测试、前端 TypeScript 检查、产品就绪与 lint 预算门禁。
