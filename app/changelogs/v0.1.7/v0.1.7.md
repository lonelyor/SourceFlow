# SourceFlow v0.1.7

## Highlights

- Completed the production write path for the AI assistant: rewrite, insert, link creation, inline translation replacement, and similar write actions now produce reviewable patches before being applied through the backend safety entrypoint.
- Replaced client-side one-time approval flags with backend-issued short-lived escalation tokens bound to the target, risk, capability, and content digest.
- Made AI Profile and Embedding API key saves explicit: real keys are not returned by the backend, and the frontend uses keep / replace / clear actions.
- Hardened `@` source context handling, security mode propagation, read-permission checks, and context budgets.
- Improved Workbench availability: related search failures degrade locally instead of breaking the main list, and the first screen now focuses on core repeated workflows.
- Improved build and release scripts with clearer status lines, duration summaries, parallel asset upload, and graceful Ctrl+C cancellation.

## AI Assistant

- Dock write tools return `previewPatch` by default instead of directly mutating notes on the default path.
- The backend patch apply entrypoint now centralizes safety checks, current-note boundary checks, live source-text validation, one-time escalation token consumption, and audit recording.
- Inline translation replacement, skill result insert/replace/link actions, and mind-map insertion now enter patch review.
- `append-note` patches can target an explicit note root while staying constrained to the current notebook.
- Empty `@` mention queries now return empty results instead of surfacing transient query errors while typing.
- Source context responses include included, dropped, truncated, and budget status; folder and batch sources use the backend-built context pack as the source of truth.
- AI session pinning persists through `ai_sessions.pinned_at`, and repeated pinning remains idempotent.
- When no real AI profile is configured, the Dock clearly asks the user to configure a provider and model before sending.

## Security And Stability

- AI security config reads and writes are normalized, and security mode now flows through chat, streaming chat, edit, tool execution, tool confirmation, source search, and context building.
- Source search and context building pass through read-permission checks, and batch thresholds account for current target and session write-risk history.
- Upload and import paths continue to enforce resource bounds: regular uploads stream with limits, imports reuse unified upload limits, and failure paths release handles and clean temporary files.
- Embedding and model-provider error response reads are capped, vector index text is truncated by characters, and failed indexing/search flows restore loading buttons.
- SQL ID/hash list queries now use placeholder helpers, and search box/path filters normalize empty values and escape literals.
- Exit sync failures that match local tree-index loss now point users to Settings > About > Rebuild index, without applying that advice to network, permission, or credential failures.

## Workbench

- The Workbench remains pinned in the sidebar by default, shows loading while opening, and displays retryable error screens for query or render failures.
- The Workbench data entrypoint normalizes backend `tags:null` values to empty arrays, fixing crashes on untagged items.
- Related-block search and secondary scope queries now degrade locally with an inline notice instead of breaking the main list.
- The first screen now prioritizes view switching, search, quick filters, selected-item batch actions, and results; advanced filters, templates, sorting, export, AI summary, and embedding tools are progressively expanded.

## Build And Release

- `编译.py` now prints stage duration summaries while keeping installer and portable packaging serial to avoid Windows output-directory races.
- `发布.py` uploads GitHub Release assets in parallel by default, computes SHA256 files in parallel, and can reuse unchanged Windows portable zips through a local manifest.
- `编译.py` and `发布.py` support graceful Ctrl+C cancellation and consistent `[RUN]`, `[OK]`, `[FAIL]`, and `[CANCEL]` status lines.

## Verification

- The release is built from matching `0.1.7` artifacts; old `0.1.6` installers are not reused as `0.1.7` release assets.
- Passed the relevant Go target tests, frontend target tests, TypeScript checks, Workbench stability checks, AI patch review / Dock runtime / Agent history regressions, and build/release script self-tests during this release cycle.
