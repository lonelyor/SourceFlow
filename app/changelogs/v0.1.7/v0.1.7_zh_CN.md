# SourceFlow v0.1.7

## 重点

- 完成 AI 助手写入路径生产级收敛：改写、插入、建链和内联翻译替换等写入动作先生成 patch 审阅，再通过后端安全入口应用。
- 单次提权改为后端签发的短期一次性 token，绑定目标、风险、能力和内容摘要，消费后立即失效。
- AI Profile 和 Embedding API Key 保存语义显式化：后端不回显真实密钥，前端通过 keep / replace / clear 区分保留、替换和清空。
- 强化 `@` 来源上下文、安全模式透传、来源读权限检查和上下文预算，减少误以为来源已纳入 prompt 的情况。
- 工作台入口和第一屏可用性增强：主查询失败可重试，关联块搜索降级不再拖垮主列表，复杂筛选和低频操作改为渐进展开。
- 构建和发布脚本支持更清晰的状态输出、耗时汇总、并行上传资产和 Ctrl+C 优雅取消。

## AI 助手

- Dock 写工具默认返回 `previewPatch`，不再在默认路径中直接写入真实笔记。
- patch apply 后端入口统一执行安全检查、当前笔记边界校验、实时原文校验、一次性提权 token 消费和审计记录。
- 内联翻译替换、技能结果插入/替换/建链和思维导图插入均进入 patch review。
- `append-note` patch 支持明确目标 note root，并限制在当前笔记本内。
- `@` 引用搜索对空 query 返回空结果，前端输入单独 `@` 时不再触发错误请求。
- 来源上下文返回纳入、丢弃、截断和预算状态；文件夹和批量来源以预算后的后端 context pack 为准。
- AI 会话置顶状态持久化到 `ai_sessions.pinned_at`，重复置顶保持幂等排序。
- 未配置真实 AI profile 时 Dock 明确要求先配置提供商和模型，避免把本地验收 provider 当成可用入口。

## 安全与稳定性

- AI 安全配置读写统一归一化，安全模式贯穿聊天、流式聊天、编辑、工具执行、工具确认、来源搜索和上下文构建。
- 来源搜索和上下文构建经过读权限检查，批量阈值按当前目标和会话写风险审计累计。
- 上传和导入路径继续收紧资源边界：普通文件上传改为有界流式写入，导入复用统一上传限制，失败路径会释放句柄并清理临时文件。
- Embedding 和模型服务错误响应读取增加上限，向量索引文本按字符截断，异步索引和语义搜索失败后恢复按钮状态。
- SQL ID/hash 列表查询改用占位符 helper，搜索 box/path 过滤器做空值过滤和字面量转义。
- 退出同步失败命中 `tree not found` / `block tree not found` 时，会明确提示到“设置 - 关于 - 重建索引”；网络、权限或密钥问题不触发该提示。

## 工作台

- 工作台默认固定侧边栏入口保持可用，打开时先显示 loading，查询或渲染失败时显示可重试错误页。
- 工作台数据入口将后端可能返回的 `tags:null` 归一化为空数组，修复无标签条目导致的 `null.length` 崩溃。
- 关联块搜索和二段 scope 查询作为增强层局部降级，失败时显示提示但不影响主列表。
- 第一屏收敛为视图切换、搜索、常用快速筛选、选中项批量操作和结果区；复杂筛选、模板、排序、导出、AI 摘要和嵌入入口放入渐进展开区。

## 构建与发布

- `编译.py` 输出阶段耗时汇总，保留 installer 与 portable 串行打包以避免 Windows 输出目录竞态。
- `发布.py` 默认并行上传 GitHub Release 资产，并行计算 SHA256，Windows portable zip 可通过本地 manifest 复用。
- `编译.py` / `发布.py` 支持 Ctrl+C 优雅取消，统一输出 `[RUN]`、`[OK]`、`[FAIL]`、`[CANCEL]` 状态行。

## 验证

- 本版本发布前按发布脚本重新生成匹配 `0.1.7` 的产物，不复用旧 `0.1.6` 安装包作为 `0.1.7` 发布资产。
- 已通过本轮关联的 Go 目标测试、前端目标测试、TypeScript 检查、工作台稳定性检查、AI patch review / Dock runtime / Agent history 回归和构建发布脚本自测。
