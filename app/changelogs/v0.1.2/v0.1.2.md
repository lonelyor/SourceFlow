# SourceFlow v0.1.2

## Highlights

- Improved Markdown migration for notes exported from Obsidian, Typora, and similar editors, including support for Obsidian image embeds such as `![[img.png]]`.
- Added attachment import from the editor context menu. Files, folders, and archives can be copied into the note assets directory and referenced with relative `assets/...` links.
- Attachment links now open with the system default app and are kept out of image, audio, or video preview rendering.
- Bold now supports multi-line and multi-block selections from the toolbar, reducing repeated edits when cleaning up imported notes.

## Markdown And Attachment Migration

- Markdown import continues to support standard image syntax and now recognizes Obsidian-style `![[...]]` image references.
- Attachment import defaults to copying files into note assets and using relative paths, reducing broken absolute-path references.
- The editor context menu offers both copy-into-note and reference-original-location modes.
- Single files, multiple files, folders, and archives are supported. Folders are copied into the assets directory as directories.
- Drag and upload flows default to relative asset references so notes and attachments remain easier to move together.

## Editing

- Applying bold to a multi-line or multi-paragraph selection now works as one batch operation.
- Batch bold covers paragraphs and heading blocks while preserving undo, focus, and toolbar behavior.
- Multi-block toolbar selections keep the real selected range instead of only applying to the first block.

## Build And Quality

- Added regression coverage for Obsidian image import.
- Added module-level checks for toolbar batch inline marks.
- Release validation continues to cover kernel regressions, frontend type checks, menu and toolbar module checks, installer validation, and portable validation.

## Upgrade Notes

- Upgrade if you migrate notes from Obsidian, Typora, or existing Markdown folders.
- Existing notes that reference attachments by absolute path can be gradually converted by importing those attachments into the note assets directory.
- Release assets include `SHA256SUMS.txt` for download verification.
