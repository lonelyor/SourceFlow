# SourceFlow v0.1.2

## Fixes

- Fixed plugin list loading when the marketplace preset points to a source that is unreachable in some networks.
- Changed the built-in marketplace preset from a single GitHub Pages source to a jsDelivr static CDN source, with GitHub Pages retained as a fallback.
- Marketplace stage loading is no longer cancelled just because a separate online probe fails.
- Plugin stage, stats, and ZIP downloads now retry through built-in mirror URLs.

## Plugin Bazaar

- The plugin publishing script now commits `version.json`, `bazaar@.../stage/*.json`, and `package/...` static root files to the plugin repository so the CDN can read them directly.
- Publishing purges jsDelivr entry cache to reduce stale `version.json` responses.
- Re-publishing an unchanged plugin preserves `updated/generatedAt` where possible to avoid needless Bazaar hash churn.

## Recommended Bazaar Source

```text
Version Info URL: https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main/version.json
Stage Base URL:   https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main
Package Base URL: https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main
Stat Base URL:    https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main/stat
README CDN Base:  https://cdn.jsdelivr.net/gh
```

## Manual Test Focus

- Open Bazaar Source, apply the recommended preset, save it, and enter the Plugins tab. The plugin list should load.
- Confirm `Paper Polish` / `sourceflow-paper-polish` is visible.
- Install, enable, and disable the plugin, then confirm note editing, saving, and sync remain unaffected.
