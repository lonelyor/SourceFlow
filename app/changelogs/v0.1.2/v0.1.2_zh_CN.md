# SourceFlow v0.1.2

## 修复

- 修复部分网络环境下使用“集市源预设”后无法获取插件清单的问题。
- 集市默认源从单一 GitHub Pages 调整为 jsDelivr CDN 静态源，并保留 GitHub Pages 备用源。
- 后端拉取集市信息时不再因为单独的在线探测失败就提前取消 stage 索引请求。
- 插件清单、统计信息和插件 ZIP 下载现在会按内置镜像顺序重试。

## 插件商城

- 插件商城发布脚本现在会把 `version.json`、`bazaar@.../stage/*.json` 和 `package/...` 静态根目录一起提交到插件仓库，方便 CDN 直接读取。
- 发布插件后会清理 jsDelivr 入口缓存，降低用户拿到旧 `version.json` 的概率。
- 重复发布未变化的插件时，会尽量保留原 `updated/generatedAt`，避免无意义改变集市 hash。

## 人工测试重点

- 打开集市源，点击“推荐预设”，保存后进入“插件”页，应能看到插件清单。
- 确认能看到 `纸面美化` / `sourceflow-paper-polish`。
- 安装、启用、禁用插件，确认笔记编辑、保存和同步主流程不受影响。
