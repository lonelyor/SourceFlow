# SourceFlow v0.1.2

## 本次更新重点

- Markdown 迁移能力增强：导入 Obsidian、Typora 等 Markdown 笔记时，补充对 Obsidian 原生图片语法 `![[img.png]]` 的识别。
- 新增附件导入能力：可从编辑区右键菜单导入文件、文件夹和压缩包，复制到笔记资源目录后以相对路径引用。
- 附件链接现在按附件处理，点击后使用系统默认程序打开，避免被误渲染成图片、音频或视频预览。
- 工具栏加粗支持跨多行、跨多个文本块批量处理，减少迁移和整理旧笔记时的重复操作。

## Markdown 和附件迁移

- Markdown 导入会继续兼容标准图片语法，并新增识别 Obsidian 的 `![[...]]` 图片引用。
- 附件导入默认复制到笔记资源目录，生成 `assets/...` 相对链接，降低绝对路径失效风险。
- 右键“导入附件”提供两类模式：复制到笔记中，或引用原位置。
- 支持导入单个文件、多个文件、文件夹和压缩包；文件夹会按目录复制到资源目录中。
- 拖拽/上传入口默认走相对路径资源引用，保持笔记和附件更容易整体迁移。

## 编辑体验

- 选中多行或多个段落后点击加粗，会在一次事务中批量应用。
- 批量加粗覆盖普通段落和标题块，并保持原有撤销、焦点和工具栏交互。
- 多块选择时工具栏继续使用真实选择范围，避免只处理首个块。

## 构建和质量

- 补充 Obsidian 图片导入回归测试。
- 补充工具栏批量行内标记的模块级检查。
- 发布前继续执行内核回归、前端类型检查、菜单/工具栏模块检查、安装包和便携包校验。

## 升级建议

- 如果你有从 Obsidian、Typora 或旧 Markdown 笔记迁移的需求，建议升级到本版本。
- 已经使用绝对路径引用附件的笔记，可以逐步通过右键附件导入改为复制到笔记内的相对路径引用。
- Release 资产包含 `SHA256SUMS.txt`，可用于下载校验。
