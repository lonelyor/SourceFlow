# SourceFlow v0.1.1

## 本次发布重点

- 发布并接入独立插件商城：`https://github.com/lonelyor/SourceFlow-plugins`。
- 新增 `纸面美化 / Paper Polish` 插件，用于优化长文阅读和写作排版。
- 插件商城支持 CDN 静态发布，并保留 GitHub Pages 备用源；笔记端可通过集市源读取插件清单、包文件和 README。
- `编译.py` 改为自洽编译入口，覆盖环境检测、依赖安装、前端构建、Go 内核构建、安装包和便携包打包。
- `发布.py` 改为自洽发布入口，只消费已经由 `编译.py` 生成并本地测试过的产物，覆盖产物收集、发布说明、GitHub Release 和校验文件。

## 插件和集市

- 默认插件源指向 `https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main/version.json`。
- 集市源拉取支持内置镜像兜底，避免单个静态源不可达时插件清单直接为空。
- 集市源支持手工配置版本信息地址、清单基地址、包基地址、统计基地址和 README CDN 基地址。
- 插件安装前展示来源、版本、权限声明和 `SHA-256` 摘要。
- 插件安装后默认不直接运行，启用前再次确认权限。
- 插件权限变更后要求重新确认，降低附加能力影响笔记主流程的风险。

## 当前插件

- `sourceflow-paper-polish`：轻量笔记美化插件。
- 支持顶部栏开关、状态栏提示、默认启用、紧凑密度和柔和对比设置。
- 不申请联网、工作区读写或宿主控制权限。
- README 内包含集市源配置教程，方便用户手工接入插件仓库。

## 构建和发布

- Windows、macOS、Linux 构建入口统一到 `编译.py`。
- 支持手工指定同系统平台和架构，例如 macOS arm64、Windows x64。
- 自动检测并安装缺失的 Node.js、pnpm、Go 和平台工具链。
- 便携包构建不再依赖外部 `scripts/portable-build.js`。
- 发布入口统一到 `发布.py`，默认发布到 `lonelyor/SourceFlow`。
- 发布说明、`SHA256SUMS.txt` 和 Release 资产由脚本自动生成。
- 浏览器扩展使用独立版本号；扩展未变更时不会为了应用版本号而强制升版。

## 稳定性修复

- 修复切换工作区后 kernel 无法读取 Electron 写出的对象格式 `workspace.json` 的问题。
- `workspace.json` 现在以对象格式 `{workspace, workspaces}` 为 SourceFlow 唯一真相源；旧数组仅作为迁移输入读取后归一化。
- 新增工作区配置回归测试，覆盖读取 Electron 对象格式、写回对象格式、启动时选中当前工作区。
- 新增统一稳定性门禁 `npm run test:stability`，覆盖脚本语法、SourceFlow 架构审计、全量 Go 回归、插件隔离冒烟和前端类型检查。
- `编译.py` 默认在构建前运行稳定性门禁；测试不通过不会继续生成安装包或便携包。
- `编译.py` 构建后会验证安装包和便携包：便携包检查目录结构并启动内核，Windows 安装包无副作用解包后检查应用结构并启动内核。
- `发布.py` 默认不重复编译、不重复跑本地 E2E；发布阶段只整理已有产物、生成校验文件、推送 tag 并上传 GitHub Release。
- 如需在发布阶段额外做本地包冒烟，可显式传入 `--validate`。
- 编译阶段的安装包和便携包验证新增主笔记流程 E2E：创建笔记、编辑、附件、搜索、导入、导出、历史快照、本地同步诊断和插件加载。
- 编译阶段的包验证会强杀内核模拟异常退出，并用同一临时工作区重启后再次检索笔记，避免主流程数据持久化退化。
- 新增产品级稳定性文档：测试门禁、运维诊断、发布回滚、插件权限和产品质量清单。
- 新增 `诊断包.py`，可本地生成脱敏诊断包，默认不包含笔记正文、不上传网络、不收集发布密钥。
- 发布资产收集只允许当前应用版本的安装包和便携包，避免旧版本残留混入 Release。
- 插件集市发布脚本避免未变化插件重复发布时无意义刷新时间戳和集市 hash。

## 人工测试建议

- 安装包安装、启动、创建笔记、编辑笔记、重启后内容保留。
- 便携包解压启动、内核启动、数据目录写入正常。
- 打开集市，信任来源，切到“插件”页，应能看到 `纸面美化`。
- 安装并启用 `纸面美化`，确认顶部栏、状态栏、设置项和开关生效。
- 关闭插件后，笔记编辑、保存和同步不受影响。
- 切换工作区后重启应用，不应再出现 `cannot unmarshal object into Go value of type []string`。

## 校验

- Release 资产包含 `SHA256SUMS.txt`，下载后可用于校验完整性。
- 插件包记录 `archiveSHA256`，安装前可在权限确认页查看摘要。
- 浏览器扩展资产名按扩展自身版本生成，例如 `sourceflow-page-saver-0.1.0.zip`。
