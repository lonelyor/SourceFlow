# SourceFlow v0.1.1

## 本次更新重点

- 重做 PDF 导出主链：预览与实际打印彻底分离，改为“静态快照 + 隐藏打印 worker + ready 握手”，减少预览页脚本、异步渲染和窗口状态对导出的干扰。
- 修复一批导出稳定性问题，包括 `Protyle is not defined`、导出页运行时污染、重复错误包装，以及 PDF 首页顶部留白过大。
- 发布独立插件集市 `SourceFlow-plugins`，并提供首个默认插件 `Paper Polish / 纸面美化`。
- `编译.py` 和 `发布.py` 收敛为统一入口，构建、打包、发布、校验和说明文件生成走同一条链路。

## PDF 导出

- 基础 PDF 继续使用 Chromium `printToPDF`，但不再直接打印活着的预览窗口。
- 打印 worker 会等待导出 runtime、字体、图片和异步渲染块稳定后再生成 PDF。
- 修复页边距与预览 padding 叠加造成的首页空白异常。
- 目录、水印、附件等后处理链路继续保留，并与基础 PDF 生成解耦。
- 导出链新增构建守卫和专项测试，降低后续回归概率。

## 插件与集市

- 默认插件源指向 `https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main/version.json`。
- 集市支持镜像兜底，以及版本信息、清单、包、统计和 README 地址的手工配置。
- 插件安装前会展示来源、版本、权限声明和 `SHA-256` 摘要。
- 插件安装后默认不直接运行；权限变化后需要重新确认。
- `Paper Polish / 纸面美化` 提供更适合长文阅读和写作的排版、紧凑密度与柔和对比设置。

## 构建、发布与稳定性

- Windows、macOS、Linux 构建统一走 `编译.py`，同系统平台和架构目标可手工指定。
- 发布统一走 `发布.py`，只消费已经编译并本地验证过的产物。
- 新增统一稳定性门禁 `npm run test:stability`，覆盖脚本语法、架构审计、Go 回归、插件隔离冒烟和前端类型检查。
- 构建阶段会验证安装包和便携包，并补充主笔记流程的自动化检查。
- 新增 `诊断包.py` 以及测试、发布回滚、插件权限、产品质量等配套文档。
- 修复切换工作区后 `workspace.json` 对象格式与内核读取不一致的问题。

## 升级建议

- 如果你之前遇到 PDF 导出失败、首页顶部空白异常，或工作区切换后启动异常，建议直接升级到当前构建。
- Release 资产包含 `SHA256SUMS.txt`，可用于下载校验。
- 浏览器扩展继续使用独立版本号，不会因为应用版本变更而被动升版。
