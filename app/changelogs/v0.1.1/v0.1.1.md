# SourceFlow v0.1.1

## Highlights

- Reworked the PDF export pipeline so preview and actual printing are fully separated. Export now runs through a static snapshot, a hidden print worker, and an explicit ready handshake.
- Fixed a batch of export stability issues, including `Protyle is not defined`, runtime bundle contamination on the export page, duplicated error wrapping, and oversized blank space at the top of generated PDFs.
- Published the standalone plugin bazaar `SourceFlow-plugins`, together with the first built-in plugin, `Paper Polish`.
- Consolidated `编译.py` and `发布.py` into the main build and release entrypoints so packaging, validation, release notes, checksums, and publishing follow one path.

## PDF Export

- Base PDF generation still uses Chromium `printToPDF`, but no longer prints the live preview window directly.
- The print worker now waits for the export runtime, fonts, images, and async render blocks to settle before printing.
- Fixed the oversized first-page blank area caused by preview padding being stacked on top of real PDF margins.
- Post-processing for outline, watermark, and attachments remains in place and is now separated from base PDF generation.
- Added export-specific guards and tests to reduce regressions in later releases.

## Plugins And Bazaar

- The built-in plugin source points to `https://cdn.jsdelivr.net/gh/lonelyor/SourceFlow-plugins@main/version.json`.
- Bazaar settings support fallback mirrors plus manual version, stage, package, stat, and README endpoints.
- Plugin install now shows source, version, declared permissions, and `SHA-256` integrity summary before activation.
- Installed plugins stay disabled by default, and permission changes require confirmation again.
- `Paper Polish` adds a calmer long-form reading and writing layout, compact density, and soft contrast options.

## Build, Release, And Stability

- Windows, macOS, and Linux builds are unified under `编译.py`, with manual same-OS platform and architecture targeting when needed.
- Publishing is unified under `发布.py` and consumes artifacts that have already been built and verified locally.
- Added the shared stability gate `npm run test:stability`, covering script syntax, architecture audit, Go regression tests, plugin isolation smoke tests, and frontend type checks.
- Build validation now checks installers and portable packages, and extends automation around the main note workflow.
- Added `诊断包.py` plus supporting docs for testing, release rollback, plugin permissions, and product quality.
- Fixed the mismatch between object-form `workspace.json` and kernel-side loading after switching workspaces.

## Upgrade Notes

- Upgrade if you previously hit PDF export failures, oversized blank space at the start of a PDF, or startup issues after switching workspaces.
- Release assets include `SHA256SUMS.txt` for download verification.
- The browser extension keeps its own version and is not bumped just because the app version changes.
