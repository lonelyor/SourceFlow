# AI 助手 GUI 冒烟清单

更新日期：2026-05-27

## 范围

- 使用 `fake` Provider 完成 AI 助手配置、普通对话、流式输出、工具 patch 预览、Agent 批量任务和历史审计主流程验证。
- 不依赖真实外部 AI 服务，不填写真实 API Key，不输出敏感信息。
- 冒烟验证只覆盖产品级主路径和已知高风险边界；性能、兼容性和真实模型质量另行验证。

## 前置配置

- Provider：`SourceFlow Fake`
- Provider ID：`fake`
- Base URL：`sourceflow://fake`
- Model：`sourceflow-fake-chat`
- API Key：留空
- 推荐设置：`temperature=0`、`maxTokens=1024`、`maxContextTokens=32768`、`maxContextMessages=8`

## 冒烟步骤

1. 无配置状态：打开 AI 助手 Dock，确认没有默认 profile 时给出可理解提示，界面不崩溃。
2. 配置状态：新建 `SourceFlow Fake` profile，确认 provider 切换自动填入 baseURL、model 和推荐参数；连通测试返回 OK；模型列表返回 fake 模型。
3. 普通对话：分别发送中文和英文问题，确认流式增量可见，最终消息保存到当前会话，metadata 标记 provider/model。
4. 工具 patch：打开当前笔记上下文并启用工具，发送“请预览追加一段 AI 冒烟测试摘要”，确认工具结果进入 patch review，而不是直接写入。
5. Patch 应用：接受工具 patch，确认内容写入目标笔记，历史记录包含 session/profile/target/results；拒绝另一条 patch 时不写入。
6. Agent 批量：在 Dock 输入多行任务创建 Agent，启动后确认任务逐项进入 review；验证暂停、恢复、取消、失败重试、接受单项和拒绝剩余。
7. 失败路径：切换到无效外部 baseURL 的非 fake profile，确认模型列表或连通测试错误清晰展示，且不会影响 fake profile。
8. 长文档：在长笔记中启用上下文后发送普通对话，确认界面可响应、上下文裁剪不报错。
9. 重复选区：选中包含重复文本的块触发改写，确认重复原文场景进入安全提示或 patch review，不自动误替换。
