# SourceFlow Page Saver

用于把浏览器里已经打开并已登录的网页保存到 SourceFlow。

## 设计边界

- 公开网页：建议直接在 SourceFlow 里输入 URL 保存
- 登录页、动态页、需要浏览器上下文的页面：使用这个扩展保存当前页
- 结果只保留 `Markdown + 本地 assets`
- 不再保存 `MHTML`

## 安装

### 方式一：直接加载源码目录

1. 打开 Chrome 或 Edge 扩展管理页
2. 开启开发者模式
3. 选择“加载已解压的扩展程序”
4. 选择当前目录：

```text
browser-extension/sourceflow-web-clipper
```

当前仓库不再保留单独的扩展打包脚本。

如果只是本地安装和调试，直接加载当前源码目录即可。

## 使用

1. 在浏览器里打开目标页面，并完成登录
2. 点击扩展图标
3. 填写：
   - Kernel URL
   - API Token
   - 目标笔记本
   - 保存目录
4. 点击“保存当前页”

## 说明

- 扩展只负责读取当前已登录页面内容和资源
- 笔记创建、Markdown 生成、资源本地化都在 SourceFlow 后端统一处理
- 首次使用请先在 SourceFlow 的“设置 -> 关于”中复制 API Token

## 已知限制

- 保存结果是 `Markdown + 本地 assets`，不是浏览器像素级还原
- `chrome://`、`edge://`、扩展页、PDF 内置阅读页、浏览器新标签页等受限页面不能保存
- 某些强依赖懒加载、跨域 iframe 或滚动后才出现资源的页面，可能只能保存正文，部分资源无法本地化

## 排障

- 点击保存没有结果：先确认 SourceFlow 内核已启动、Kernel URL 可访问、API Token 正确
- 笔记本列表获取失败：通常是内核地址或 Token 错误，也可能是当前网络无法访问本机内核
- 登录页保存内容不完整：先刷新页面并等待内容完全加载，再重新保存
- 公开网页优先直接用 SourceFlow 的 `URL 导入`，只有登录页和动态页再用这个扩展
