# SourceFlow 插件权限说明

插件不是主笔记流程的一部分。插件异常不得影响创建、编辑、搜索、同步这些主流程。

## 权限原则

- 默认最小权限。
- 使用网络必须声明 `network.http`。
- 使用 Worker 必须声明 `runtime.worker`。
- 使用 Node 外部模块必须在 `allowedRequireModules` 中声明。
- 未声明权限的能力应被插件运行时拒绝或熔断。

## 商城包要求

插件包必须包含：

- `plugin.json`
- 入口脚本
- 版本号
- 权限声明
- README 或说明文档

商城提交必须包含：

- 包名
- 版本
- 下载 URL
- `archiveSHA256`

发布门禁会校验本地包哈希，避免清单指向的包和实际包不一致。

## 熔断要求

- 插件加载失败只记录错误，不阻断笔记启动。
- 插件权限不足只禁用该插件能力，不提升权限。
- 插件网络失败不影响本地笔记。
- 插件崩溃不应破坏工作区数据。

## 用户提示

安装插件前应展示：

- 插件名称和版本。
- 发布者。
- 权限列表。
- 数据访问范围。
- 网络访问说明。
